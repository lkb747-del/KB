# 우리 반 습관 도장

초등학생이 매일 스스로 습관을 체크하는 교실용 웹앱입니다. 기본 습관은 **양치질 · 아침활동 · 1인1역**이고, 선생님이 바꿀 수 있습니다.

설치할 것 없이 `index.html` 파일 하나를 브라우저(크롬, 웨일, 엣지 등)로 열면 바로 쓸 수 있어요.

## 학생은 이렇게 써요
1. 교실 태블릿이나 전자칠판에서 앱을 열어 둡니다.
2. 자기 이름을 누릅니다.
3. 오늘 한 습관 카드를 누르면 초록색으로 바뀝니다. 다 하면 **‘참 잘했어요’ 도장**이 찍혀요.
4. 아래에서 이번 주 도장과 연속 기록을 볼 수 있어요.
5. **다 했어요**를 누르면 다음 친구 차례입니다. (40초 동안 가만히 두면 처음 화면으로 자동으로 돌아가요.)

## 선생님 메뉴 (오른쪽 위 ‘선생님’, 처음 비밀번호 `0000`)
- **오늘 현황**: 학생별 체크 표, 날짜 이동, 기록 고치기, ‘아직 안 한 친구’ 목록
- **주간 기록**: 월~금 표, 달성률, 도장 수, 엑셀용 표 복사
- **학생·1인1역**: 번호·이름·역할 입력, 명단 한꺼번에 붙여 넣기 (`이름, 역할` 한 줄에 한 명)
- **습관 항목**: 습관 이름·그림·설명 바꾸기, 최대 6개
- **설정·백업**: 반 이름, 비밀번호 변경, 백업 파일 저장/불러오기, 기록 지우기

처음 열면 예시 학생 8명과 예시 기록이 보입니다. ‘우리 반 학생 넣기’에서 실제 명단으로 바꾸면 예시는 사라져요.

## 알아 둘 점
- 기록은 **그 기기의 브라우저 안에만** 저장됩니다. 서버로 보내지 않아서 학생 정보가 밖으로 나가지 않아요.
- 그래서 **교실 기기 한 대를 함께 쓰는 방식**에 맞습니다. 학생마다 다른 기기에서 쓰면 기록이 합쳐지지 않아요.
- 브라우저 기록(사이트 데이터)을 지우면 기록도 사라지니, 가끔 **설정·백업 → 백업 파일 저장**을 해 두세요.

## 인터넷에 올려 쓰기 (선택)
GitHub 저장소 설정의 **Pages**에서 이 브랜치를 선택하면 주소로 열 수 있습니다. 이 경우에도 기록은 각 기기에 따로 저장됩니다.
